
# European Flight Delay Prediction 

## Proposal

I plan to use the European Flight Delays 2023-2025 dataset from Hugging Face - https://huggingface.co/datasets/345rf4gt56t4r3e3/flight-delays-europe-2023-2025

This dataset contains per‑flight delay estimates for European commercial flights from January 2023 to December 2025, derived from the Open Performance Data Initiative (OPDI) flight‑list data published by Eurocontrol.

My goal will be to build a classification system that will predict whether a flight is likely to be delayed by at least 15 minutes based on the departure and destination airports, operator, aircraft type and date etc.
